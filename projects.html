E-Commerce Website Task

Designed responsive UI using HTML, CSS, and Bootstrap. Integrated JavaScript for product filtering, single-product views, and cart checkout using Fake Store API.

Technologies Used:
HTML CSS Bootstrap JavaScript Fake Store API
Problem Solving Challenges:
  • Finding the right public API was difficult because many APIs lacked required fields like price, reviews, or product images. After researching multiple sources, I selected Fake Store API as it provided complete and consistent data.
  • Implementing filtering based on category, price, and rating required creating multiple conditions and ensuring proper DOM updates.
  • Building a single-product page dynamically was new, and I learned to use URL search parameters to fetch detailed product data.
  • Product images were not storing correctly inside localStorage, and after debugging, I fixed this by refetching product data on cart load.
  • Managing add-to-cart, delete-item, updating total price, and tax calculation needed structured logic and reusable functions.
  • Ensuring the cart resets after placing an order required clearing localStorage and updating the UI state correctly.

Product Management CRUD System

Built a complete CRUD system for product management using React, Node.js, Express.js, and JWT authentication. Implemented API integration, secure data handling, and interactive UI functionality.

Technologies Used:
Node.js Express.js React.js JWT
Problem Solving Challenges:
  • The first challenge was that I was still learning. I had completed my basics of Node.js and Express, using the built-in methods to create a server and handle requests and responses. Since I was already familiar with the MVC structure, it was easier to understand how routes handle the request and then the controller executes the business logic. That’s how it works, and I was still learning while building this project.
  • I was also somewhat familiar with JWT tokens. I read about them and implemented them to check whether a token was being generated for the correct user or not. At first, it was not generating because of a hashed password issue — I was not converting the plain text password using bcrypt again to compare it with the stored hashed password. Once I fixed that, the password matched and I was able to generate the JWT token for login.
  • I faced a multer issue in the product section. The images were uploading locally, but after deployment on Render, it wasn’t working. Later, I realized it was an environment variable problem — I had forgotten to add the security key in the Render deployment environment.
  • Only logged-in users can access their own products, and they are allowed to delete, update, and edit only their own products.
