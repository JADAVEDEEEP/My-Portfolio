AI · Full stack · New

LeadScope — AI Lead Intelligence

A lead research platform for digital marketing agencies. The agency describes its type, services and requirements; the Express backend runs a two-stage Gemini pipeline — candidate discovery, then final research — and returns the single strongest client opportunity with everything needed to act on it.

Features

  • Candidate discovery and evaluation, then selection of a #1 primary recommendation with relevant competitors.
  • Consistent 100-point scoring (agency/ICP fit, service fit, marketing opportunity, business potential, need, buying signals) with HOT / WARM / LOW PRIORITY / POOR FIT bands.
  • Six business outputs for the #1 company: lead generation strategy, AI & automation workflow, lead scoring breakdown, personalized cold email, digital marketing ideas and KPI targets.
  • Candidate pool saved to Google Sheets through the Google Sheets API.
  • Dark black / white / red interface with a live API status indicator.
  • The backend also contains an automated discovery & qualification pipeline: public-web company discovery, website verification that respects robots.txt and rate limits, deduplication, batched AI scoring computed server-side, top-10 ranking and a separate final AI evaluation, with MongoDB storage and resumable background jobs.

Technologies

ReactViteTailwind CSSNode.jsExpress.jsGemini APIGoogle Sheets APIMongoDB · MongooseREST API

Full stack · Auth

Product Management System

Built a complete CRUD system for product management using React, Node.js, Express.js, and JWT authentication. Implemented API integration, secure data handling, and interactive UI functionality.

Technologies

Node.jsExpress.jsReact.jsJWT

Problem-solving challenges

  • The first challenge was that I was still learning. I had completed my basics of Node.js and Express, using the built-in methods to create a server and handle requests and responses. Since I was already familiar with the MVC structure, it was easier to understand how routes handle the request and then the controller executes the business logic.
  • I implemented JWT tokens to check whether a token was being generated for the correct user. At first it was not generating because of a hashed password issue — I was not comparing the plain text password with the stored bcrypt hash. Once I fixed that, the password matched and I was able to generate the JWT token for login.
  • I faced a Multer issue in the product section. Images uploaded locally, but after deployment on Render it wasn't working — I had forgotten to add the security key in the Render environment variables.
  • Only logged-in users can access their own products, and they can delete, update and edit only their own products.

E-Commerce Website

Designed responsive UI using HTML, CSS, and Bootstrap. Integrated JavaScript for product filtering, single-product views, and cart checkout using Fake Store API.

Technologies

HTMLCSSBootstrapJavaScriptFake Store API

Problem-solving challenges

  • Finding the right public API was difficult because many APIs lacked required fields like price, reviews, or product images. After researching multiple sources, I selected Fake Store API as it provided complete and consistent data.
  • Implementing filtering based on category, price, and rating required creating multiple conditions and ensuring proper DOM updates.
  • Building a single-product page dynamically was new, and I learned to use URL search parameters to fetch detailed product data.
  • Product images were not storing correctly inside localStorage, and after debugging, I fixed this by refetching product data on cart load.
  • Managing add-to-cart, delete-item, updating total price, and tax calculation needed structured logic and reusable functions.
  • Ensuring the cart resets after placing an order required clearing localStorage and updating the UI state correctly.

Technologies

Problem-solving challenges

  • Implementing AOS (Animate On Scroll) library to replicate the smooth animations originally created with Framer Motion.
  • Ensuring all assets and image paths were correctly referenced after moving from a build-step environment to a static structure.
  • Optimizing the site for mobile devices using Bootstrap's grid system and media queries.
